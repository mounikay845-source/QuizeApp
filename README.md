**QuizApp** is a clean, interactive quiz and knowledge assessment application built with vanilla web technologies. It provides engaging multiple-choice trivia challenges with score tracking and instant answer evaluations.

---

## 🌐 Live Application

👉 **[https://mounikay845-source.github.io/QuizeApp/](https://mounikay845-source.github.io/QuizeApp/)**

---

## ✨ Features

- **🎯 Dynamic Question Engine:** Renders multiple-choice questions with randomized answer choices.
- **⚡ Instant Feedback:** Visual cues highlighting correct vs. incorrect selections.
- **📊 Final Score Summary:** Displays total score upon completion with performance feedback.
- **🔄 Play Again:** Instant reset button to retry the quiz without refreshing the browser.
- **📱 Responsive UI:** Clean card layout styled with custom CSS for all screen sizes.

---

## 🛠️ Tech Stack

- **Structure:** HTML5
- **Styling:** CSS3
- **Logic:** Vanilla JavaScript (`Script.js`)
- **Hosting:** GitHub Pages
